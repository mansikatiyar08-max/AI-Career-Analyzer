# AI Career Analyzer

An AI-powered career guidance web application that analyzes a user's skills, interests, and career goals to provide personalized career recommendations.

## 🚀 Features

- AI-powered career recommendations
- Skill gap analysis
- Recommended skills
- Personalized learning direction
- Dynamic AI-generated insights

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Generative AI

## 🔄 How It Works

User Input → Gemini AI → Career Analysis → Skills & Learning Recommendations
